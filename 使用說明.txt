小黑的永恆插件更新器

1. 更新器放哪裡：將分享 ZIP 完整解壓縮到桌面等可寫入的資料夾即可。
   不需要把更新器放進遊戲的 _forever_ 或 AddOns；保留解壓後的整個資料夾一起使用。
2. 點兩下「永恆插件更新器.exe」。朋友不需要另外安裝 Python 或 Git。
   原本桌面的「永恆插件一鍵更新」捷徑和「開啟更新器.vbs」也可使用。
3. 按「選擇資料夾…」，選擇朋友自己的 World of Warcraft 遊戲資料夾。
   可以選含 .build.info 及 _forever_ 的根目錄，也可以選 _forever_、Interface 或 AddOns。
   例如遊戲在 D:\Games\World of Warcraft，就選這個 World of Warcraft 資料夾。
   選好後，視窗會顯示「插件自動裝到」的完整路徑：
   D:\Games\World of Warcraft\_forever_\Interface\AddOns
   插件由更新器自動放進去，不用自己搬動或解壓插件。
   程式會確認是《永恆》客戶端，並記住選定的位置。
4. 完全關閉《魔獸世界》，按「一鍵更新遊戲插件」。
   清單裡未安裝的插件會從作者正式來源下載安裝；已安裝的插件會檢查更新。
   也可以先按「只檢查」，只檢查不會建立遊戲或更新基準資料夾。
5. 等狀態列顯示完成，確認「需查看」為 0，再啟動遊戲。

整合內容包括 Lueur、AtlasLoot、ThreatClassic2、Questie、QuestieDB、BetterBlizzFrames、
Forever Loot Sparkles、Shortest Path Forever、Leatrix Maps、Zone Info Forever、
Minimap Button Drawer、WhatsTraining、DBM 核心、五人副本及團隊／世界首領模組，
另附小黑插件總入口。首次安裝會套用隨附的繁中修改，包括 AtlasLoot 永恆地城與團隊名稱。
QuestieDB 是資料庫，沒有獨立設定視窗；Questie 設定可從小黑總入口開啟。
RestedXP、AmobiCompanion、Forever Quest Pins 不在安裝清單內。
這個按鈕只補裝上述整合清單中的插件，不會安裝網路上的所有插件。

表格列出本機與發布版本，雙擊該列可看完整結果。
更新器會比對已安裝插件、原版 ZIP 與新版 ZIP，保留可合併的本機繁中及其他修改。
遇到衝突、下載失敗、版本不符、必要依賴未裝或找不到舊原版 ZIP，會顯示原因並保留現況。
如果現有版本與作者最新版相同，可從作者原版建立更新基準，保留現有修改。
若現有版本比作者新版更高，則保留現有版本。
沒有可信來源的其他插件只列出略過，不會自動修改。

遊戲開著時只允許檢查；安裝及更新前必須完全退出遊戲。
更新成功並驗證後，當次舊插件及舊原版 ZIP 會送至資源回收筒。
更新失敗會嘗試還原；若回收失敗，表格會顯示保留檔案的位置。
目前版本的原版 ZIP 會保留，供下次更新比對；不同遊戲位置使用不同的原版基準。
請保留更新器旁的 baselines 或 clients 資料夾，不要每次只搬動 exe。
查看保留檔案會開啟所選遊戲同一磁碟上的 _codex-backups/一鍵更新。

分享時只需傳朋友分享版 ZIP；不要附上自己的 WTF、帳號或角色設定。
更新來源為作者 GitHub 正式發布頁，或經 CFWidget 查版後從 CurseForge CDN 下載。
朋友首次執行及下載需要網路。未來作者修改同一段翻譯而產生衝突時，仍需要手動處理。


GitHub 線上更新

「一鍵更新遊戲插件」：更新所選《永恆》_forever_/Interface/AddOns 裡的插件，
並補裝整合清單中缺少的插件；按下時會自動同步最新插件清單、繁中修改和小黑總入口。
「更新管理器介面（UI）」：只更新這個管理器視窗程式。有新版介面時會顯示提示並啟用按鈕，
下載驗證完成後自動關閉管理器、更換新版並重新開啟。上次的exe會保存在.updates資料夾。
管理器介面更新不需要移動或重新選擇遊戲資料夾，settings.json和原版ZIP會保留。

GitHub連不上時會沿用上次成功下載且驗證通過的整合清單；第一次離線則使用內附清單。
遊戲插件本身仍需連到作者來源查版及下載；離線不等於可以離線下載插件。
請保留更新器旁的online資料夾，裡面保存整合版本與三方合併需要的舊翻譯。

線上發布位置：https://github.com/littleblackmann/wow-forever-addon-updater/releases
第一次使用線上功能，請先下載本版；更早沒有線上功能的版本仍需手動換一次。


v1.1.1 更新說明
修正管理器介面更新後可能無法自動重新開啟，以及相鄰但互不重疊的文字修改被誤判為衝突。
若目前是 v1.1.0，第一次更新完成後沒有自動開啟，直接再開一次 exe 即可；
也可下載最新版 ZIP 換上新版，保留原本 settings.json、baselines／clients 與 online 資料夾。
