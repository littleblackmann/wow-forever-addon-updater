# 小黑的永恆插件管理器

方便安裝與更新《魔獸世界：永恆》插件的 Windows 懶人包。
清單內的插件由各原作者製作，並非本人開發；本人僅整理安裝更新流程與部分繁中內容。本工具非官方提供。

[下載與圖文介紹](https://littleblackmann.github.io/projects/forever-addon-manager.html) · [GitHub 最新發行版](https://github.com/littleblackmann/wow-forever-addon-updater/releases/latest)

下載 ZIP 後，完整解壓到桌面等可寫入的位置，開啟「永恆插件更新器.exe」，不需另外安裝 Python 或 Git。

1. 選擇裡面有 `_forever_` 的 `World of Warcraft` 資料夾。
2. 確認畫面的插件安裝位置，可以先按「只檢查」。
3. 完全退出遊戲，再按「一鍵更新遊戲插件」。
4. 完成後查看結果，有「需查看」項目就雙擊該列查看原因，再重新啟動遊戲。

- **一鍵更新遊戲插件**：更新整合清單內的遊戲插件、補裝缺少項目並同步中文內容。
- **更新管理器介面（UI）**：只更新這個 Windows 管理器，有新版時才啟用。

請保留管理器整個資料夾，讓程式記住遊戲位置與更新資料。手動換新版時，只更換 exe，保留其他檔案。
遇到下載失敗或個人修改需要處理時，會保留原插件並顯示原因。
更新管理器後若沒自動開啟，先手動再開一次 exe；仍無法開啟時，從上方網站重新下載最新版。

給朋友時請分享原始 ZIP 或網頁連結，避免一併傳出自己的本機路徑與使用紀錄。
第三方插件與中文內容的相關授權歸各原作者，來源可由網站整合清單查看。
